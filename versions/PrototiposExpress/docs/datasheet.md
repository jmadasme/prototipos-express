## Que es PrototiposExpress

**PrototiposExpress** es un servicio profesional de prototipado rapido que convierte ideas en prototipos funcionales de software y hardware. El servicio opera bajo un modelo innovador donde el cliente no realiza ninguna inversion inicial: el prototipo se desarrolla, se entrega para pruebas, y solo si demuestra valor real para el negocio, el cliente paga por el servicio.

### Valores fundamentales

- **Sin riesgo**: El cliente no arriesga capital. El prototipo se desarrolla antes de cualquier pago.
- **Velocidad**: Prototipos funcionales en dias, no en meses.
- **Calidad**: Cada prototipo pasa por controles de calidad rigurosos.
- **Confidencialidad**: No se revelan nombres de clientes ni detalles de proyectos previos.
- **Versatilidad**: Capacidad para prototipar en 9 areas tecnologicas diferentes.

### Mercado objetivo

- Empresas que necesitan validar una idea antes de invertir en desarrollo completo.
- Startups que requieren un MVP (Producto Minimo Viable) rapido para presentar a inversionistas.
- Departamentos de innovacion que necesitan explorar nuevas tecnologias.
- Empresas establecidas que buscan automatizar procesos con prototipos funcionales.

## Como solicitar una reunion

### Requisitos previos

- Un navegador web moderno (Chrome, Firefox, Edge, Safari).
- Conexion a internet.
- La informacion basica de tu proyecto lista.

### Instrucciones paso a paso

1. **Abre la pagina** en tu navegador.
2. **Familiarizate con el servicio** navegando por las secciones "Como funciona" y "Tecnologias" para asegurarte de que PrototiposExpress puede cubrir tu necesidad.
3. **Haz clic en "Solicitar reunion"** (boton en el menu de navegacion o en el hero).
4. **Completa el formulario** con tus datos:
   - Proporciona informacion veridica y completa.
   - En el campo "Describe tu necesidad", se detallado: explica tu idea, el problema que resuelve, el publico objetivo y cualquier restriccion tecnica que conozcas.
   - Selecciona un plazo realista.
5. **Haz clic en "Enviar solicitud"**.
6. **Espera la confirmacion**: La pagina mostrara un mensaje verde de exito si todo funciona correctamente.

### Validaciones del formulario

El formulario valida los siguientes aspectos antes de enviar:
- Todos los campos obligatorios deben estar completos.
- El correo electronico debe tener un formato valido (ej: `usuario@dominio.com`).
- El telefono debe tener entre 7 y 20 caracteres, permitiendo digitos, espacios, `+`, `(` y `)`.
- La fecha de plazo debe ser posterior al dia de hoy.
- Cada campo muestra un mensaje de error especifico si no pasa la validacion.

## Que esperar despues del formulario

### Inmediatamente despues del envio

- La pagina mostrara un mensaje de confirmacion: "Solicitud enviada con exito. Te contactaremos en un maximo de 24 horas para agendar tu reunion sin costo."
- Si ocurre un error, se mostrara un mensaje con la descripcion del problema. Los errores comunes incluyen:
  - "No se pudo conectar con el servidor" (problema de red o backend caido).
  - Error de validacion del servidor (datos invalidos).
  - Error de configuracion del correo (problema interno).

### Proceso posterior

1. **Recepcion del correo**: El equipo de PrototiposExpress recibe tu solicitud por correo electronico con todos los datos formateados en un email HTML profesional.
2. **Contacto inicial**: En un maximo de 24 horas habiles, recibiras una respuesta para agendar una reunion (puede ser presencial o virtual).
3. **Reunion de analisis**: Durante la reunion, el equipo profundizara en tu necesidad, alcance, restricciones tecnicas y plazo.
4. **Propuesta de prototipado**: Se definira que tecnologias se usaran y el alcance del prototipo.
5. **Desarrollo**: El equipo desarrolla el prototipo funcional.
6. **Entrega y pruebas**: Recibes el prototipo para pruebas sin costo.
7. **Evaluacion**: Si el prototipo aporta valor real, se acuerda un modelo de servicio.

### Tiempos estimados

| Etapa | Tiempo estimado |
|-------|-----------------|
| Recepcion de solicitud | Inmediato |
| Primer contacto | 24 horas maximo |
| Reunion de analisis | 2-3 dias habiles |
| Desarrollo de prototipo | 1-4 semanas (segun complejidad) |
| Periodo de pruebas | 1-4 semanas (acordable) |

## Preguntas frecuentes (FAQ)

### Sobre el servicio

**P: ?Realmente no hay costo inicial?**

R: Si. Desarrollamos el prototipo funcional sin cobrar nada por adelantado. Solo si el prototipo demuestra valor real para tu negocio, acordamos un modelo de pago justo. Si no hay valor, no pagas nada.

**P: ?Que pasa si el prototipo no funciona como esperaba?**

R: El equipo de PrototiposExpress se asegura de que el prototipo sea funcional y cumpla con los requerimientos acordados. Si durante las pruebas identificas areas de mejora, podemos ajustarlo dentro del alcance acordado.

**P: ?Que tipo de proyectos puedo prototipar?**

R: Cualquier proyecto que involucre las tecnologias que ofrecemos: aplicaciones web, software de escritorio, servicios backend, dispositivos IoT con WiFi/BLE/LoRa/RF, sistemas embebidos con Ethernet, y combinaciones de estas.

**P: ?Atienden solo en Santiago?**

R: Tenemos disponibilidad para movilizacion nacional. Contactanos para confirmar disponibilidad en tu region.

**P: ?Cuanto tiempo toma obtener un prototipo?**

R: Depende de la complejidad del proyecto. En la reunion de analisis definiremos un cronograma realista. Los prototipos simples pueden estar listos en una semana; los mas complejos pueden tomar hasta un mes.

### Sobre la landing page

**P: ?Que navegadores son compatibles?**

R: La pagina es compatible con Chrome (60+), Firefox (55+), Edge (79+) y Safari (12+). En navegadores antiguos, las animaciones pueden no funcionar, pero el contenido y el formulario siguen siendo accesibles.

**P: ?Puedo enviar el formulario sin conexion a internet?**

R: No. El formulario requiere conexion a internet para enviar los datos al backend. Sin embargo, la pagina en si puede cargarse si ya esta en cache.

**P: ?Que datos personales se recopilan?**

R: Solo los datos que ingresas en el formulario: nombre, correo, telefono, empresa, necesidad y plazo. Estos datos se envian por correo electronico al equipo de PrototiposExpress. No se almacenan en base de datos.

**P: ?Es seguro enviar mis datos a traves del formulario?**

R: El formulario se comunica con el backend a traves de HTTP/HTTPS. Para entornos de produccion, se recomienda que el backend sirva bajo HTTPS. Los datos se envian en el cuerpo de la peticion HTTP y por correo electronico interno.

### Sobre tecnicas de uso

**P: ?Puedo usar la pagina sin JavaScript?**

R: No completamente. El formulario requiere JavaScript para la validacion y el envio. Las animaciones y la navegacion suave tambien dependen de JS. Sin JavaScript, la pagina se ve pero el formulario no funciona.

**P: ?Como se si mi solicitud se envio correctamente?**

R: La pagina mostrara un mensaje verde de exito. Si ves ese mensaje, tu solicitud fue recibida. Si ves un mensaje rojo de error, algo salio mal; intenta nuevamente o contactanos directamente por otro medio.

### Sobre el modelo de negocio

**P: ?Como determina PrototiposExpress si el prototipo "aporto valor real"?**

R: El valor se determina en conjunto con el cliente durante el periodo de pruebas. Si el prototipo resuelve el problema identificado, optimiza procesos, genera ahorros o abre oportunidades de negocio, se considera que aporto valor. La decision final es del cliente.

**P: ?Que pasa si quiero quedarme con el prototipo pero no pagar?**

R: El modelo se basa en la confianza y en relaciones de largo plazo. Si el prototipo aporta valor real, esperamos que el cliente cumpla con el acuerdo. Nuestro objetivo es construir relaciones comerciales duraderas, no proyectos unicos.

## Solucion de problemas

### Problemas con el formulario

| Problema | Causa posible | Solucion |
|----------|---------------|----------|
| El formulario no envia | Backend no disponible | Verifica que el servidor Flask este corriendo en `localhost:5000` |
| Mensaje "No se pudo conectar con el servidor" | CORS bloqueado o backend caido | Revisa la consola del navegador (F12) para ver errores de red |
| Validacion de email falla | Formato incorrecto | Usa el formato `usuario@dominio.com` |
| Validacion de telefono falla | Demasiados o muy pocos digitos | Asegura 7-20 caracteres, solo digitos, espacios, +, (), - |
| Fecha de plazo no se acepta | Fecha pasada o igual a hoy | Selecciona una fecha a partir de manana |
| El boton "Enviar" no responde | JavaScript deshabilitado | Habilita JavaScript en el navegador |

### Problemas con el backend

| Problema | Causa posible | Solucion |
|----------|---------------|----------|
| Error 500 al enviar formulario | SMTP no configurado | Verifica que `.env` tenga `SMTP_USER` y `SMTP_PASS` correctos |
| Error "Authentication failed" | Contrasena de aplicacion incorrecta | Regenera la contrasena de aplicacion en Google |
| Error "Connection refused" | Puerto SMTP bloqueado | Verifica que tu red no bloquee el puerto 587 |
| Error "Timeout" | Red lenta o Gmail no responde | Intenta nuevamente en unos minutos |
| El servidor no inicia | Puerto 5000 en uso | Cambia el puerto con `export PORT=5001` |

### Problemas de visualizacion

| Problema | Causa posible | Solucion |
|----------|---------------|----------|
| Los iconos no se ven | FontAwesome no cargo (sin internet) | Verifica la conexion a internet |
| Animaciones no funcionan | Navegador muy antiguo | Actualiza el navegador o usa Chrome/Firefox reciente |
| Diseno desordenado en movil | CSS no cargo correctamente | Recarga la pagina (Ctrl+F5) |
| Menu no se abre en movil | JavaScript deshabilitado | Habilita JavaScript |
